# H3 新机制筛选：建议一个局部判别，保留一个备选

2026-10-04；独立判断，0 GPU、0 模型调用、无代码修改。采用 problem-formulation；限 3 个定向检索 query，随后读一手原文。**优先 SwiGLU 成对误差，QK 几何列为备选；两者均是可证伪的问题，尚非创新 claim。** E059 的数值控制失败没有判定激活来源；E061 仅停止固定 smooth 初始化。这里不恢复两者，不要求实验前已经证明视频收益。

现有动机是 H3 的同状态残余不能由简单通道偏差/输出比例解释，且改变局部误差大小尚未稳定改进整模结果。它不足以归因任何层，却值得检查“线性层误差经过实际非线性后，什么被消去、什么被耦合”。实际源码为 [H3 DiT](/home/wjq/workspace/DiffSynth-Studio/diffsynth/models/minimax_h3_dit.py:124)：fused QKV 后 Q/K 各经 head RMSNorm→RoPE；fused fc1 后为 `SiLU(g)⊙u`。研究对象是视频 W4A4 校准/表示设计者；不重开模态重加权、中心聚类、全局 scale、历史补偿或普通 kernel 修复。

## F1（优先）：SwiGLU 是否把成对投影残余转换为值得单独表示的误差？

**具体问题。** 同一真实输入的 native fc1 同时产生 gate/up 残余。现有线性低秩支路能否充分处理它们经乘法耦合后的误差，还是有限预算应表示一个非线性残余？不是再问“乘法会放大 outlier”。令 teacher 为 `(g,u)`，native 为 `(g+e_g,u+e_u)`，`φ=SiLU`，存在精确四角分解：

`Δh = a+b+c`，`a=[φ(g+e_g)−φ(g)]⊙u`，`b=φ(g)⊙e_u`，`c=[φ(g+e_g)−φ(g)]⊙e_u`。

**可区分预测。** 若问题成立，经过同一个 BF16 down 权重和实际 AdaLN gate 的线性映射 `D` 后，`c` 有稳定正的净能量作用 `ΔE_c=||Dc||²+2〈D(a+b),Dc〉`，且去除普通通道常数/输出比例后仍在；其作用不能仅由两个边际误差大小解释。若 c 很小、主要抵消，或普通中心校正已解释，则该二阶表示路线停止。大 `||c||`、gate/up 权重相关或异常值本身均不够。

**一次有效最小实验。** 固定既有 p30/s5、p36/s14 两个 teacher 输入，预选 block 0/24/49（不据结果选层）。仅捕获各处 BF16 fc1 输入；原 native fc1 在**同一完整输入**局部重放，保留真实 global/pack，再取预定 video 行。用已实现输出形成四角，在 FP32/FP64 做恒等式与带符号分解；主结果为经过同一 D 的误差，不混入 down 自身 A4。完整 native/teacher 输出无需 oracle 加回，也不绕用软件 QDQ。两次 teacher 捕获加局部重放足够启动，现有资产如无逐字节同输入不能冒充已有配对。以保持 `e_g/e_u` 各自通道均值、方差的预定行错配作辅助零假设；它不保持内容条件相关，故只用于判断是否超出边际统计，不能单独作因果证明。六个层×状态全部报告，不当作六个独立视频样本。

**能改变决定的结果。** 两状态中同一预选层的正 `ΔE_c` 均达到总 `||DΔh||²` 的 20%，且有限样本恒等式数值误差低于 1%，才推进一次直接干预；否则停止此候选，不换层找阳性。20%是预先提出的资源门槛，不是统计定理。阳性也只建立局部表示需求，尚不能解释 E056 的跨步相干或生成质量。

**可能方法与最强平凡解释。** 如该结构成立，可考虑把现有 BF16 bottleneck 的部分预算移到乘积后，使用共享投影 `z=Ax` 的少量二次特征 `z_i z_j` 解码残余；与相同参数/乘加预算的普通线性 pre/post adapter及普通 block reconstruction比较。它必须实际利用成对结构，不能只是加一个 MLP；尚未证明可学、可部署或新颖。最强普通解释是一般 SwiGLU 非线性与有色误差，或一阶项主导、c反而有利。NVFP4 预训练工作已分析 SwiGLU 权重对齐及 outlier 放大并给出通道补偿，覆盖宽泛故事；**没有据此认定其已覆盖这里的实际误差四角、符号作用及同预算非线性残余表示。** [原文 §3.2–4](https://arxiv.org/html/2602.02047v1)。非线性 adapter 的直接先例尚未完整查清，不能先宣称创新。

## F2（备选）：QK 的功能近零方向是否消耗了固定低秩容量？

**具体问题。** fused qkv 的 rank32 校正统一按线性输出/权重误差组织，但 Q/K 的径向误差经 RMSNorm 近乎消失，V没有这一性质。是否存在**可重复的容量错配**：大部分原始 QK 重构改善落在近零功能方向，而小的联合切向残余决定 attention 输出？只证明归一化有径向不变性不是贡献。

对单 head，`n(q)=Γq/s`，`s²=||q||²/d+ε`，其 Jacobian 为 `J=Γ[I−qqᵀ/(d s²)]/s`；径向导数为 `Jq=Γq ε/s³`，并非含 ε 时严格为零。Q/K 改变后的 score 必须保留双侧及交叉项，不能仅给 Q、K 各自乘一个敏感度标量。

**最小有效实验与否证。** 可复用 F1 同次 teacher 捕获的相同三层输入，重放原 native QKV；保留 norm 参数、RoPE、BF16 attention 和 V。先直接比较实际径向/切向有限残余，及现有 LR 对二者的带符号作用，不只比较范数。对 Q/K 共同移除径向或切向分量后重算精确 attention 输出；用同 raw-MSE 的随机方向作普通各向异性零假设。若径向校正占比不大，或简单 Q/K/V 重加权、输入协方差加权即可解释全部收益预期，停止这条复杂几何路线；**径向 oracle有效本身仅复现数学**。下一步成立条件是预定两状态均出现“raw QKV MSE改善，却几乎不改善规范化后 attention”的同一容量错配；不需要预先有整视频阳性，但也不凭此开始全模型训练。

**方法结构及残余边界。** 潜在解是直接求解共享 rank 的 Q/K 联合低秩因子，使其作用于 norm→RoPE→双线性 score 的可见方向，并在同一预算内保留 V；部署仍是一份 W4和原 rank支路，不添加 logits侧缓存。这不同于更换 SVD 初始化，但若只得到普通 block loss拟合，则不够。 [QERA §III](https://arxiv.org/html/2410.06040v1)已覆盖输入协方差加权的线性误差最优低秩解；[HeadQ §3](https://arxiv.org/html/2605.03562v1)已覆盖 attention可见误差、softmax零空间与key-cache低秩score校正。尚待回答的是**pre-norm W4A4、Q/K同时受扰、共享固定rank**下是否有现成独立度量不能处理的约束，而不是泛称“几何感知量化”。最强平凡解释是普通 sensitivity-weighted PTQ已足够，或实际主要损伤在 V/MLP。

**执行建议：只先冻结 F1 的捕获/数值合同，F2最多复用捕获做读出，不并开训练线。** 初次实验的价值是区分线性容量不足与实际非线性耦合，允许明确阴性；后续是否值得论文级投入还须同预算强基线与独立视频质量证据。以上均未执行，不新增正式 claim、不修改旧停止判据。

## 执行前窄查新更新

两次额外定向检索找到直接近邻，收窄上面的“可能方法”：

- [SPEAR §3.1、§5.4](https://arxiv.org/html/2606.11244v1)已经在量化低秩补偿中使用 `B[gamma(Ax)*Ax]`，以输入相关门控提高补偿能力；泛化非线性/门控量化 adapter 已被覆盖。其局部展开也可含二次项，单换成二次特征差异很薄。
- [NA-LoRA §3.2 Proposition 3.3](https://arxiv.org/html/2606.31717v1)已分解 SwiGLU gate/up 残余的非线性输出作用，并讨论 gate 敏感性下的低秩预算。它是训练期 LoRA，不是本次真实 W4A4 有害交互测量，但“线性误差不代表门控功能误差”不属于新命题。
- [AuroRA §2.2–2.3](https://arxiv.org/html/2505.18738v1)是通用非线性 bottleneck PEFT 近邻，不能把 `B sigma(Ax)` 本身认领为新结构。

E062 只执行 F1 的有界诊断，QK 不并开。阳性亦不自动开展 generic adapter 训练，须先证明具体成对结构/放置位置提供超出上述近邻的必要性与同预算收益。阴性停止本次乘性交互路线，不以换名字复活。
