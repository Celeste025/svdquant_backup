# H3 量化误差拓扑：2026-10-30 临时选题记录

状态：探索候选，**不是已证实的新方法或论文主张**。

## 信号与问题

E105/E106 两个固定 H3 case 中，完整 DiT 每步输出误差的 NMSE 近似不变，但把真实误差位置随机置换后，最终视频相对 BF16 的 RGB NMSE 分别从 0.5191/0.5720 降到 0.03737/0.2972。高斯与等幅随机误差亦明显改变终点。该实验不能区分空间相关、跨帧相关、通道偏置、跨 timestep 相关、模态交互及误差方向；随机置换需要 BF16 oracle，不能部署。E103/E104 已发现真实误差具有时空聚集。

问题：同等误差能量下，视频 DiT 的何种误差结构最伤害闭环生成？可否把 FP4 量化的误差重新分配到低敏感的时空/通道模式，而不增加权重位数或推理时 teacher 调用？目标读者是低比特视频生成的算法与算子研究者。

不解决：仅靠调 timestep 比特数、复制 BF16 权重、一般性量化加稀疏融合、视频压缩编码，以及将到 BF16 的像素距离直接称为主观质量。

## 候选可证伪主张

1. C-topology-mechanism：控制每步/每模态误差能量和边际直方图后，时空低频相干性比重尾/通道均值更能预测并因果改变生成轨迹和动作细节。反证：单因素置换与 matched controls 的结果不稳定，或全由误差方向/通道偏置解释。
2. C-topology-method：用固定 FP4 权重表示的离线 codeword/scale 优化或低开销激活 rounding，把完整 DiT 输出误差从高敏感模式移开；在相同在线延迟下优于最强 PTQ/QAD 参照。反证：只有 oracle 能改变拓扑，真实可部署规则无效或开销抹掉加速。
3. C-budget：以误差拓扑而非局部 NMSE 为准，分配稀疏注意力 tile/精度预算，可得到新的 quality–latency Pareto。近邻极多，暂时 parked。

## 查新碰撞（截至 2026-10-30，有限检索）

- PulseQuant（arXiv:2609.33384）已有传播风险和响应子空间的 4-bit codeword 修正，覆盖“传播敏感度校准”；不能把这一点作为新意。
- DSAQuant（arXiv:2609.04031）已有按去噪阶段区分监督和推理引导；FPSAttention（arXiv:2506.04648）已有 timestep-aware 的 FP8+sparse 联合设计；不能称按 timestep 配精度新颖。
- QuantSparse（ICLR 2026）已有量化+稀疏联合优化和二阶稀疏 attention 重参数化；不能仅把两项组合当贡献。
- Q-VDiT（arXiv:2505.22167）已有时空相关维护蒸馏；一般性的 temporal loss 不新。
- 通用 dither/噪声整形早已存在。剩余可能的新内容是：**在真实低比特视频 DiT 中建立受控的误差拓扑—闭环质量因果关系，并给出保持 NVFP4 runtime 形式的拓扑定向实现**。此残余仅“部分查新”，尚不能说没人做过。

## 决策性实验

探索模式，先不训练/写 kernel。固定 H3 两原 case，再加 6–10 个预注册未见 prompt/seed。每一步在各臂自身输入上计算 BF16 和量化输出，用可逆的单因素干预分别破坏：空间位置、视频帧顺序、通道排列、跨 timestep 对齐；严格保持每模态每步误差能量与边际直方图，同时报告有符号相关与频谱。随后做相同强度的随机/低频/高频 synthetic controls。以配对终点 latent/RGB 距离、动作/细节盲评、音画同步和 source quality 指标分别评价，不把 BF16 距离当主观质量。

若只有完全随机置换有效，而没有稳定的单一结构因素，停止机制主张。若机制成立，再测试最小可部署干预：固定权重 NVFP4 下的激活局部 scale/rounding 或离线 FP4 code 编辑；必须保留真量化 GEMM、只用一份权重，并测端到端速度。若真实干预不能在相近 latency 改善独立视频质量，停止方法主张，最多保留分析论文方向。
