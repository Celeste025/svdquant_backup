## 问题与证据缺口

**Q：H3 现有 native NVFP4＋rank32 配方，在不同深度产生的局部误差，去掉普通通道 bias 后，经真实 BF16 后缀传播到同一 video 输出空间，是否仍有超过“保持源误差二阶几何”的随机残余的正相干？** 待区分的是残余的有符号方向与内容/后缀的特定耦合，不是后缀会放大误差这一事实。H3 的共享残差流与共同输出头提供架构动机，但没有现成的深度证据。

[报告057](../reports/057_20261004_h3_qknorm_radial.md) 已停止 F2 径向容量解释；[报告056](../reports/056_20261004_h3_swiglu_interaction.md) 已停止 F1 乘性交互修正，均不重开。[报告051](../reports/051_20261004_h3_temporal_diagnostic.md) 的跨时间相关不能移作跨深度证据；[报告052](../reports/052_20261004_h3_update_arithmetic.md) 说明交互范数大不等于有害。[E059](../reports/053_20261004_h3_activation_oracle_control.md) 是数值门槛失败，不是机制阴性。当前缺的是同一 teacher 输入上各层残余的**共同终端坐标、带符号交叉项和强随机对照**，而不是更多局部 MSE。

## 最小可判别实验建议（不是冻结执行计划）

固定已有两份 teacher 状态 p30/s5、p36/s14，预选 block 0/24/49，固定现有 smooth、rank32 和 native 执行合同，不挑层找峰。以一个完整 block 为替换单位，在完整真实 teacher 输入上得到块出口残余 E_l；其余块 BF16。不同层 hidden cosine 不作判据。

1. **先去普通解释。** 各层 E_l 在 video 行上去逐通道均值，其他模态维持 teacher；此中心化残余是解释性干预，不是新的部署配方。分别注入并通过各自真实后缀，得到共同 video velocity 坐标的 δ_l。终端再使用由同一 teacher 固定的线性投影 P 去除逐通道常数/输出比例，对所有臂完全相同。
2. **保留几何的 null。** 对中心化残余的薄 SVD `E_l=U_l Σ_l V_lᵀ`，独立生成预定的模式符号 `D_l=diag(±1)`，用 `E'_l=U_l Σ_l D_l V_lᵀ` 注入同一位置。它精确保留源总能量、奇异谱、channel Gram `EᵀE` 和 token Gram `EEᵀ`，再经过相同 BF16 后缀，因而比各向同性噪声强。只在终端打乱方向不能排除后缀敏感性。少量固定 null 种子只作投入筛查，不报显著性 p 值；同时报告传播后的能量与单位范数方向，防止只比较不同放大量。若全量 SVD 超出诊断预算，应事先冻结同一 token 子集用于真实/null 两臂，明确结论仅限该支持集，不能事后挑行。
3. **把相干与交互分开。** 令 `d_l=Pδ_l`、`A=Σ||d_l||²`、`C=(||Σd_l||²−A)/A`。真实 C 与同源 null 比较，不把三层张量低秩当新发现。再做一次三块同时 native 的前向，比较 `Pδ_joint` 与单块 native 结果之和；单独报告差项的**有符号净能量效应**。完整 native 与中心化干预分列，不能将二者偷偷混成一个精确分解。若省略此步，结论只能是 teacher 上的固定残余性质。

所有注入先检验实际 BF16 写回误差；零注入精确重放，源残余能量/Gram 的保存误差必须远小于要判别的差距。若不满足，标记控制无效并停，不作机制阴性，也不追加精度网格。SVD null 保留两侧 Gram，不等于保留所有 token×channel 联合二阶项，也打破误差与 teacher 内容的高阶关系；超过它仍不能单独归因于码舍入，更不能称已排除所有普通有色噪声。

## 投入与停止

建议只在两份固定输入都出现实质正 C、均超过预定匹配 null 的范围、且真实 joint 仍有同向净增强时，再询问是否存在可用少量既有 LR 参数控制、跨输入稳定的终端方向。此时也只获得方法设计动机：任何后续结构必须相对 CLQ 式后缀校准、普通 bias 及同校准成本的联合重构给出额外预测与收益；单纯改 loss 或联合调 codes 已有直接覆盖。

若去 bias 后消失、匹配 null 足以解释、两输入方向不复现，或实际 joint 不保留增强，停止这个具体深度相干候选，不扩层/提示找阳性、不转训练。**本轮不凑第二个问题，也不把一次机制阳性预先命名为创新。**
