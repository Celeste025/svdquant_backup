# H3 方法候选再筛：本轮保留 0 个 active 候选

2026-10-04；独立只读筛查，使用 problem-formulation。0 GPU、0 模型调用、0 实验代码修改；未接触 E068/E073 私有映射。仅本页新增，未改共享 state。结论是本轮没有找到值得为其启动实验的方法剩余，不是认为 W4A4 已无研究空间。

**出发点及限制。** E065b/E066 的四状态×200层局部 video SSE 全改善、完整 DiT SSE 反转，只否定这两个候选之间的非负逐层 SSE 重加权排序，尚未识别画质损伤。E075 的固定一次相位干预及局部 BF16 oracle 都未出现明确可辨修复；它停止该单层单步窗口，不能证明误差结构普遍无关。不能把两者拼成“需要约束某种新几何量”的证据链。以下是本轮真正展开的两项假设及其退出理由。

**1．联合去噪场的非互易响应是否是局部 SSE 看不见的损伤？——不立项。**

设想：量化使联合 video/audio 去噪场产生额外环流，局部重构更好却沿生成轨迹反复偏转；方法出口原拟是对低秩修正施加互易约束，而不是逐层加权。具体读出可在固定时刻、两个预定有限扰动方向上，以中心差分比较 `u·Δ_v f−v·Δ_u f`，并分开 BF16 与 native，不能对离散量化直接套无穷小导数。

但“非互易就是有害”的前提不成立。H3 的输出是 velocity，video/audio 又有不同噪声时间表，不能不作变换便把其 Jacobian 当 score Hessian。更根本地，[Horvat 与 Pfister，ICLR 2024 官方摘要](https://proceedings.iclr.cc/paper_files/paper/2024/hash/d553f0e0abb80e2a60328d634583bd2e-Abstract-Conference.html)明确说明：守恒性对正确采样及密度估计既非必要也非充分。BF16 网络也没有被结构性约束为梯度场。因此就算 native 的该统计显著增大，仍不能推出该删去什么、为何会改善视频；这是缺少带方向的因果预测，不只是“已有文章谈过 curl”。本次仅核该官方摘要，未声称复证全部定理。

若以后重新提出，最小决定性实验必须是：在正确参数化和固定共同状态下，仅消除新增非互易成分，与等改变量的对称成分干预比较完整后缀功能；两者都有效、BF16 本身同样不互易，或只有统计下降无功能恢复，都否定该特异解释。**当前没有低成本且可识别的此类分解/干预，也没有可部署约束带来的额外收益预测；不先花 GPU 测一个即使阳性仍无法决策的 curl 数字。**

**2．V 与 out_proj 的共同坐标选择能否绕开独立局部最优？——只属已有方法对照。**

这是可执行的结构自由度：逐 head 令 `V′=VA`、`W_o′=A⁻¹W_o`，则精确算术下 `P V′ W_o′=P V W_o`，且变换可离线折入两侧权重。H3 的 head_dim=128 允许直接采用既有 Hadamard 选择；不需要新增完整前向或在线旋转。Q/K 保持原式，因此它也不是重新开发 FP4 attention。

然而，[QuaRot §4 Stage 1c，式7–9](https://arxiv.org/html/2404.00456v2#S4.SS3)已明确利用同一 V/out_proj 恒等式、逐头权重融合和量化。独立小 agent 也得到同一候选及同一退出判断。本地换成 NVFP4、保持 rank32、按实际 attention 输出择 A，都还没有指出现有重参数化无法满足的约束。任意可逆 A 的更大搜索域亦不自动构成贡献。

它最小可检验的是固定 block24、两个既有完整输入，比较 identity 与预先固定的逐头 Hadamard：两侧真实重打包并重新构造同 rank 支路，Q/K 与实际输入绑定，BF16 等价误差单列；不能只旋转已解码 V 而遗漏 out_proj 的 A4。若 attention/block 输出无稳健改善即停止；即使阳性，也只证明一个已有基线变体适合 H3，需要完整视频确认收益，不能解释 E065/E066 或成为新的机制。**本轮不建议为这一直接复现另开实验。**

**为什么没有用其它未测项凑第三候选。** E062 的停止只针对 gate/up 乘性交互，确实没有否定 SiLU 单支曲率；但从“尚未测过”直接到曲率 oracle/非线性 adapter，仍缺少区别于 SPEAR、NA-LoRA 和普通偏差补偿的可部署预测。同样，胞元内低秩响应、真实激活残差支路、时间/模态分支和 scale 支持问题已有专门筛查；本轮没有获得使其重开的独立证据。这里没有要求先证明画质阳性才能提出假设，而是要求拟做的最小实验无论阴阳都能改变明确的方法选择。

本页没有新增 claim、校准任务或 GPU 计划。后续若主线提出另一具体结构，可直接设计反方实验；不把本轮的 0 候选解释为暂停用户的研究任务。
