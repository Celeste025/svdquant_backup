## 1. 固定 V microscale 组会不会把物体运动变成与显存组边界锁定的纹理闪动？

**来源与反常处。** E038/E041 的真实观察是：固定 native SVD 线性层，只改变 attention 后，拍手视频的手部轮廓可辨性下降；这不是统一动作变慢。现有 attention V 沿 token 轴分组，H3 视频为 T-major、W-fast 的 37×18×32 网格。一个移动物体会改变哪些局部特征共享 V scale；因此可以预言：同一物体的细节误差可能随其跨越固定组边界发生变化，即便平均 V/attention 输出 MSE 相近。**尚未观测到这个运动对齐效应；也没有根据把现有重影归因 V。** 视频 token 起点还有 text+audio 前缀偏移，不能未经实际标签核对就称“每行恰好两组”。

**问题与对象。** 对部署视频低位 attention 的方法/系统研究者，有意义的问题是量化布局是否制造一种稳定的、随物体运动而触发的额外质量代价，以及硬件可消费的分组能否避免该代价。不是证明重新分组会改变输出，也不是再给所有 heads 搜索六种空间排列。

**竞争解释。** (a) QK 错配造成多帧/多位置混合；(b) P 舍入或 scale 改变混合权重；(c) 普通 V 重构误差及 decoder 敏感性；(d) 自由轨迹分叉后本来就是不同的手部/构图；(e) 量化分组的普通位置依赖，没有任何运动特异后果。

**若以后有运动锁定证据，最小有效实验。** 使用同一实际 post-RoPE Q/K/V，冻结 Q/K 和高精度 P，仅改变 V 的 16-token 组成员，量化后逆置换回原逻辑位置再计算 PV；控制原 packets 的纯搬移、相同量化误差能量的分组，以及不含量化的同样搬移。先回答 V 单独是否足以产生随组边界移动的误差，不能改变 P/V 两条路径后归因 V。若要声称“随运动闪动”，还必须使用已可靠识别的物体轨迹对齐残差，固定坐标的奇偶谱不足。这个 CPU/小算子实验只排除归因，不构成视频机制验证；支持后才有理由作一次同状态的完整预测干预。

**最近先例及残余。** [PAROAttention §3/4.1/4.3](https://arxiv.org/html/2506.16054v1)已将视频三维展平、分组分布与低位 attention 联系起来，并按 head 选六种轴排列；其主要量化困难是 P，不是本文预言的运动对齐 V 效应。[DeltaQuant](https://hanlab.mit.edu/projects/deltaquant)的三维局部分组已在本地碰撞记录中核查。E018 已经在同一 H3 证明 Qmean 分组相位可改变误差方向，平均 MSE 几乎不变，同时普通伪边界也出现结构。故“换 Q 为 V、换128为16”没有自动形成新问题。潜在残余是**运动触发的质量代价与硬件固定组的不可兼得约束**，不是分组数学本身；当前两项都未证实。

**决策：不启动。** E018 的局部非平凡数值阳性已未能建立视频后果；现在 V 版本没有独立观察升级动机。只有已保存视频/张量先给出可重复的运动锁定现象，或真实部署布局提供无法用现成重排/局部分组解决的约束，才重新考虑。不能把 E055 的 2×2 阴性当本假设反证，也不能因此再换尺度无期限寻找周期。

## 2. H3 native 量化是否损伤内容邻域内的响应稳定性，而端点 MSE 和同 teacher 状态读出看不见？

**来源与反常处。** H3 中更小的局部 attention NMSE 没有稳定改善完整视频；这只建立了代理失效，尚未建立“响应稳定性”解释。明确预言是：在 BF16 已经具有可读、稳定响应的同一内容邻域里，native 量化的局部输出增量会出现大于一般有限精度及同能量误差的额外不稳定，且它影响同一个事件的可辨性。**这一预言未观测。** “存在 code 翻转/不连续”本身是普通量化事实，不能用作结果。

**竞争解释。** BF16 自己在所选邻域就不稳定；扰动改变真实语义或时刻；普通量化误差足以解释输出差；仅数值导数很大但有限步生成没有后果；视频差异源于允许的随机构图变化。native/软件代理算术差别亦须单独控制，不能归入新机制。

**最小有效实验。** 只有先有可读的 BF16 邻域，才固定一个真实 H3 状态和一个具有语义定义、幅度预定的小扰动，比较 BF16/native 的成对有限差分，而不是无限小 Jacobian。BF16 输入/输出 BF16 台阶应作为控制；量化误差大小、条件变化大小和 BF16 响应本身必须分别报告。要求读出在 BF16 内稳定，并区分“相同单点误差、不同响应差异”是否预测同一事件的可辨性。若 BF16 前提不成立、差分仅随误差能量增长，或只有码值变化无行为差异，即停止，不能扩大扰动/文本网格直到阳性。

**最近先例及残余。** 本地 [conditional_response_collision](../01_literature/conditional_response_collision.md) 已核查 DASH/GAMP、关系/Jacobian 匹配；E012 的现成语义差分读出没有通过 teacher 稳定性门槛。另见 [solver_quantization_collision](../01_literature/solver_quantization_collision.md)：真实 code 边界、BF16 本身非光滑、模型偏差与数值积分误差应分开，H3 实际是固定 Euler，不能借自适应求解器叙事补出需求。因此“差分损失/鲁棒蒸馏”已是直接近邻。可能残余只能来自**一个已验证的内容邻域、实际 native 边界导致的特定行为失效、以及已有关系蒸馏在相同执行预算下不能恢复的原因**，目前三项均缺。

**决策：不启动，不把它注册为 E012 的新名字。** 缺 teacher 稳定性不是量化机制阴性，但也不是再提出相同实验的正当动机。这里最需要的不是新的差分公式，而是一条不用反复筛提示就可观测、可判真的局部行为。
