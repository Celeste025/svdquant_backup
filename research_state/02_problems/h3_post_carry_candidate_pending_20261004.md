**判断：0 个建议立即推进的新方法候选。** 这不是从局部阴性断言整个空间已空，也不要求实验前已有决定性阳性；本轮缺的是一个有明确结构、能在成熟对照之后留下贡献的干预。Carry-Q 的输赢都不能填补这个缺口。下面只保留一个数学上清楚的问题，说明它为何目前仍应停在问题层。

**唯一筛查问题：同一固定高精度预算，到底缺“保护正确的输入信息”，还是仅缺正确求解已有分解？** 对方法设计者，真正重要的是能否在一份 NVFP4 主权重、rank32 BF16 两因子、一次主 GEMM＋两次小 GEMM 的预算内，恢复主路径已经丢弃、当前支路又未保留的有用信息。不能把 rank32 收益小直接归因为表示不足；固定 smooth 的初始化实验和待完成的 carry-Q 都只覆盖特定求解配方。

取行输入 X、列向权重 W，记 Xq 为实际 packet 解码，L 为 rank32 矩阵。SVD 型输出的实数展开为

`Xq Q(W−L) + XL = Xq[Q(W−L)+L] + (X−Xq)L`。

同一个 L 同时控制有效权重重构和激活残余的读出，确有约束；但“不同时最优”不是新机制。设 E=X−Xq，在主权重量化暂时移除的条件下，最优保护方向由 `EᵀE` 而不是 `XᵀX` 决定，是已有可解子问题。也不能因量化胞元内存在被 rank32 投影遗漏的变化，就断言存在真实任务损伤：那只是一般信息损失，任意合成 nullspace 扰动都能制造。

**可区分预测。** 信息选择解释预言：在完全相同的真实 packet、rank/字节和校准预算下，由 E 的功能残余决定的固定支路，应在预先留出的 prompt 上继续恢复 carry-Q 未恢复的线性层输出；优势不能仅来自拟合样本上多选几个候选。竞争解释是：已有求解未收敛；E 的有用方向本来可由普通残差加权低秩得到；或更好保护 E 同时使 `Q(W−L)` 变差，净收益消失。后两项有成熟直接先例，不能把它们称为未知空白。

| 最强近邻 | 直接覆盖与准确边界 |
|---|---|
| [ARHQ，§2–3、§5.3](https://arxiv.org/html/2605.00140v1) | 直接构造 `G=EᵀE/N`，对 `WG^(1/2)` 做加权截断 SVD，推理仍为量化主支＋高精度低秩支路。它明确只精确解 activation-residual 子问题，承认重数量化可能恶化；报告也未完整给出全部 native 数值合同。故“残差协方差选高精度方向”已被覆盖，H3/native 复现属于强对照，不能利用其实现缺项认领方法。 |
| [TwinQuant，§4.1–4.3](https://arxiv.org/html/2606.01556v1) | 直接面对分解后两分量量化难度耦合，学习全局正交及低秩内部可逆变换，并量化低秩支路。其具体参数族与 BF16 rank32 残余支路不完全同构，不能说它已优化所有 L；但“联合学习更量化友好的分解＋融合”不是剩余贡献。 |
| [ResQ，§4](https://arxiv.org/html/2412.14363v2)；本地 [HeadQ/QUADS 边界](../04_prior_work/h3_activation_residual_representation_20261004.md) | ResQ 已在输入子空间分配精度；HeadQ 已保留实际量化残余的低秩坐标，QUADS 已直接消费 native 激活残余。因此从 X 改读 E、改为高精度子空间、加第二次残余量化，都不能仅凭 H3 设置立题。 |

**尚可能新在哪里，当前缺什么。** 上述来源没有替我们回答“真实 H3 对同一 packet 条件下，是否存在成熟等预算线性保护仍未保留、而某个特定可部署表示能保留的任务相关信息”。一个新结构及其排他预测即可成为实验动机，不要求事先证明所有线性方法不可能成功。现在没有这种结构：门控通用 adapter 撞 SPEAR，保留邻近 token 公共分量撞 DeltaQuant，普通实际残差读取撞 HeadQ/QUADS；本页不把“条件化表示”当作占位方法名。不做 F1/F2、跨时间互补、模态权重、patch 边界、深度反馈或数值精度网格的改名重启。

**便宜判别的能力与限制。** E065/b 全部冻结且独立检查完成后，已有 8 条各层 `xs/target/actual packet` 足以定义一个无需 DiT 的固定样本对照：预先按 prompt 留出，而非随机拆相关 token；使用相同 activation packet，比较现有支路与 ARHQ 式残差加权保护的留出误差。权重主包须对各自 `W−L` 按同一规则重新构造，另列该变化，不能换 L 却沿用不匹配的旧残差主权重。若只做 CPU 解码矩阵乘，这是候选/表示分析，不能称 native 效果；8×8 witness 也不能恢复全部未选中候选输出。若成熟加权分解已解释收益，就没有新表示证据；若未解释，也**不能**据此证明新的表示必要性或视频改善。目前不建议为它另开实验，因为尚无将其阳性转成独特干预的构造。

**按效果与成本停止，而非沿用普适百分比。** 若成熟等预算分解已解释留出收益，停止新表示 claim，记基线改进。若剩余改善不超过数值实现误差及 prompt 留出波动，停止从局部 SSE 外推；若只增加 side 信息/解码流量而没有在同质量下减少实际总成本，停止效率 claim。只有候选的最佳可信效果仍有机会优于现成方法的质量—时延—存储边界，才值得完整 native/视频投入；本地尚无可据此填入的质量等价容差，不能杜撰一个 20% 作为科学必要条件。

**Carry-Q 完成后的决策边界。** 先完成已约定的独立检查与四 teacher 读出。稳定收益意味着旧基线不足，应更正基线；不稳定或无收益只排除这份固定配方，不能证明 ARHQ、完整 SVDQuant 或高精度表示整体失效。两种结果都不自动构成新机制实验的动机；后续研究仍在用户已有授权内自主推进。当前不分配 claim ID、不推荐第二个题目、不启动新 GPU 实验；本轮新增的是 ARHQ/TwinQuant 的精确近邻约束，而非又一次局部阳性要求。
