# H3 动作相位尚在、身份边界不可读：问题筛选

2026-10-04；反方只读审阅，0代码/0GPU。本地范围为[报告037](/home/wjq/workspace/svdquant-exp/research_state/reports/037_20261003_clapping_readability.md)与E041两seed观察；额外只核两篇primary。与 hypothesis_reset 代理交叉讨论过候选1。**可以保留一个可证伪候选，当前证据不足以称“多解叠加”或新机制，也不足以启动一套attention hook工程。**

确实存在的观察：E038固定同一套native SVD线性层，只改attention；E041两seed低位臂有多层手部轮廓、边界难读，r0前段仍保留近似开合相位，r1 coarse16也有快速开合。BF16标签只指attention，不是完整BF16模型。这个观察可动机化attention来源问题，不能直接改写成主线W4A4线性层配方的已证缺陷。

可保留的精确候选是：**近对称的两只手接近/遮挡时，对象之间的匹配差距较小；量化扰动使一些query把质量分给错误对象或错误时间的轨迹。整体开合节律仍由其他信息保留，但对象身份与边缘不再单一。** 它比“运动消失”“attention熵变大”具体：预测是对象身份映射的正确性有额外功能作用，而不是只要缩小总体attention误差就一样好。高熵可同时关注同一对象的多个patch，低熵也可稳定选错；熵和top-1反转本身都不等于物理身份歧义。

最强替代解释是**单帧手部几何/纹理已被普通误差破坏，周期性位置/遮挡只是使它更难读**。r0低位臂前段就有多层边缘，并非只在某次交叉后突然出现；r1还混有主体尺度与取景差。局部重复手指可能是生成几何错误、模糊或decoder对latent误差的响应，不一定来自其他帧/另一只手。现有观察没有给重影逐一标明来源，也没证明一次遮挡前后发生身份交换。报告已排除“全部由最后时间blend产生”，未排除更一般的解码/空间误差解释。视频后半帧更差，不说明故障在后半**denoising step**。

两篇最近邻限定了新意边界，但不代替本假设的检验：

- [QuantWM §3.2–3.3、§4.2](https://arxiv.org/html/2609.26425v1#S3.SS3) 已直接研究小K误差造成时空token错选、模糊/闪烁，以及query子空间低秩补偿。故“保持attention排名/修复logit”本身已经覆盖。其因果语境是2bit因果KV缓存；本文尚可能剩下的是**近对称对象接近/遮挡条件下，身份特异的路由错误及其可读性后果**，不是换成H3/4bit就算新。
- [VC-Attention §3.1–3.2](https://arxiv.org/html/2609.15810v1#S3.SS2) 已有V异常值/分组误差分析，聚类后共同置换K/V、减均值及恢复公共项，也在H3评估。普通V误差是必须面对的竞争解释；该文的共同K/V置换保持全精度attention函数，而本候选的诊断会刻意改变P到对象token的分配，两者不是同一个操作。此差别本身仍非创新证明。

**一个最小、可改变决定的干预合同：身份正确的P权重交换，对照错对象/错时交换。** 这是后续候选实验说明，本轮未实施。

选一个预先固定、双方可读的共同轨迹锚点和小query集合，先确认从这个锚点不修复的量化续跑确实再现身份/边界缺陷。不能用旧E038从初始noise走来的量化片，冒充新锚点的未干预control。对象对应必须独立确定；BF16自由轨迹最终手部mask不能直接贴到已经分叉的量化中间状态，latent token也不是精确的单像素身份标签。

对量化产生的实际有效P，只交换同frame、两个对应对象key上的权重值。正确臂把较大质量分给预先规定的同一对象；sham臂交换错时或错误身份的匹配pair。保留同样V、同样权重multiset、row-sum、熵和swap数量；sham还要匹配|Δp|及输出扰动幅度。单pair的精确变化是 `(p_b−p_a)(v_a−v_b)`，所以只匹配swap数量远远不够。禁止搜索强度或事后挑最有效的head/step。冻结后续采样/decoder，盲读完整片中身份连续性、手部边界和开合相位；不以局部SSE下降代替最终缺陷救援。

**固定V仍不足以排除V解释：** 改变P也改变了 `Σp·(Vq−Vb)`，可能只是在避开V异常值。sham应尽可能匹配该误差曝光；若做不到，阳性最多支持“对象对齐的重分配有用”，不能写“已排除普通V-outlier”。要进一步归因P来源，需要独立V域对照，而非现在扩大成多臂工程。

决策只有三种：正确映射相对相配sham有稳定、可读的救援，才继续研究这个身份条件；两者相似，优先普通输出去噪/误差解释；共同锚点无法复现缺陷、真实P无法取得、身份对应或sham无法可信匹配，则是**不可识别/当前不可实施**，不是科学阴性。即使得到阳性，这仍是有teacher/标注的诊断oracle，距离无oracle的可部署新方法尚远。

当前更经济的前置工作就是root正在做的完整媒体确认：缺陷究竟主要在单帧就已存在，还是可清楚追踪的对象在接近/分离后发生身份混淆。若前者占主导，应先保留“空间可读性损伤”，不要强套时序对应故事。无需因为generic邻近方法存在就否定所有未检验机制，也无需为保留一个候选立即建runner。

**先做的唯一媒体必要条件检查（无需新kernel）：闭合事件是否真是新增身份歧义的条件。** 预先只看 r0 三臂的0–32帧，不选后段最坏帧：初始分离0–2；第一闭合外观3–5及再分离6–8；第二闭合9–11及再分离12–14；随后再分离窗口19–21、25–27、31–32。这些窗口依据原E041事件表；“闭合外观”仍不代表物理接触。实际三臂page00覆盖0–15、page01覆盖16–31、page02仅取32，路径为 `/data1/models/svdquant-wjq/research/20261003/E041/vbench0161_r0_{bf16,global_mean,coarse16}_page{00,01,02}.png`，来源映射见[frame_index](/home/wjq/workspace/svdquant-exp/results/research/E041/frame_index.json)。

问题只问：在实际确已分离、无遮挡且可见的帧，低位臂是否已经有同样的额外手指/重轮廓？闭合之后是否出现原先可分的两手身份持续无法恢复，而不是已有模糊跟着同一只手移动？不要从无法辨认的纹理猜身份；能用袖口/戒指跟踪才记录身份交换，否则写unknown。单帧几何错误与跨帧身份交换分开标记，不统计新的总次数。

若错误在0–2已存在，并在至少两个后续无遮挡分离窗口持续、又没有新增身份交换的可辨证据，这将**削弱“可见接近/遮挡触发的身份混淆”这一具体版本**，优先单帧几何/纹理失真解释，足以决定暂不开发该版本的路由救援hook。它不全局否定attention错配：H3可双向看全片，前部视频帧仍可能受后部token影响；同时“没有观察到交换”也不等于证明交换不存在。反之，若前段边界清楚而在闭合后出现可跟踪的错身份持续，才为上述特定干预提供比“有重影”更强的动机，仍不是机制证明。本次只给固定查看窗口，未声称已完成新标注。
