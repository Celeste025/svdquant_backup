# H3 深度路径：输入依赖项没有产生预期的净误差放大

2026-10-04，E064。**停止本次“输入漂移与量化块形成稳定有害反馈”的候选。** 完成了真实路径来源诊断和独立核验，没有新方法或生成质量改善。

## 动机 / 观察

此前完整 H3 对照中，plain 与 legacy SVD 的最终误差大小有时接近，但方向明显不同：p36/s14 的视频 SSE 比约 0.999，误差向量 cosine 只有 0.467。固定 smooth 的低秩初始化替换也没有一致改善。这些现象本身并不新颖，但提示应先定位差异来源，而不是继续改局部损失。

本次问题：沿一个完整 DiT 的真实深度路径，已经偏移的输入是否让当前量化块产生额外的、稳定有害的误差？竞争解释是普通 BF16 传播和 teacher 输入上的局部误差已经解释主要能量，额外项反而发生抵消。跨层累积、跨块校准和有限差分递推已有[CLQ](https://arxiv.org/html/2509.24416v1)及[跨层联合补偿](https://arxiv.org/html/2607.14630v1)等先例，分解本身不计创新。

## 实验

固定 H3 CFG1 两个既有状态 p30/s5、p36/s14，预选 block 0/12/24/36/49，同时保留 plain 和 legacy SVD 各自完整路径。完成 **6 次完整 DiT、70 次局部 block 重放**，实际 960 次 native GEMM/pack、752 次 BF16 SDPA。所有完整路径复现历史；四角使用完整输入和原 metadata，各自正常重新量化。

令 B/Q 为 BF16/量化 block，hB/hQ 为各自真实输入，保存四角后用 FP64 计算：

```
q = Q(hB) − B(hB)                 teacher 输入上的局部误差
p = B(hQ) − B(hB)                 BF16 块对输入偏移的响应
c = [Q(hQ) − B(hQ)] − q           量化块的输入依赖项
e_out = p + q + c
net_c = ||e_out||² − ||p+q||²
```

正 net_c 表示增加误差，负值表示抵消。另存输入误差及 `p−输入误差`，避免把残差连接的恒等传递叫作放大；按相同模态行域去通道均值后重复全部统计。第0块输入完全相同，因此四个配方×状态对照的 p/c 均严格为零。

GPU 执行 467.429 秒，峰 allocated 40.90 GiB，保存张量 24.546 GB；worker/tmux 已退出，GPU0 已释放。无训练、新视频或 MJ。

## 结果 / 结论

下表为 video 的 `net_c / ||e_out||²`，单位 %；每格为 **原始 / 去通道均值后**。第0块全部为0，不列入机制判据。

| block | p30 plain | p30 SVD | p36 plain | p36 SVD |
|---|---:|---:|---:|---:|
| 12 | −0.34 / −0.56 | −0.42 / −0.53 | −0.36 / −0.50 | −0.40 / −0.47 |
| 24 | −0.94 / −0.96 | −1.19 / −1.17 | −1.57 / −1.63 | −1.19 / −1.36 |
| 36 | −3.39 / −3.43 | −2.78 / −2.81 | −2.70 / −2.89 | −2.59 / −2.68 |
| 49 | −2.63 / −2.79 | −2.22 / −2.41 | −1.05 / −1.08 | −1.13 / −1.10 |

**16个非零深度对照均为净抵消。** c 自身能量却占总误差 2.17%–15.87%，说明交互项范数不能替代有害作用。预设条件要求某臂至少两个深度在两状态都达到原始及去均值后 ≥20% 的正净作用；两臂通过深度均为0。不追加后缀干预、训练或层/提示搜索。

**净抵消也不等于量化块更稳定。** 为防止这一误读，额外对同一 Gram 做解释性展开：`net_c=[||p+c||²−||p||²]+2<q,c>`。16格第一项全部为正，占总误差 1.83%–13.44%；第二项全部为负，抵消了这部分增加。该事后读出不改变原判据，独立复核同样确认。它不证明一般收缩性，也不是可部署修复。

结论仅限这些状态、预选深度及两种旧配方的块级净能量作用；不是完整生成轨迹或视频质量结论。c 包含权重量化、激活量化、非线性和 BF16 算术，**尚未区分 W/A 来源**。不能据净能量变化小就说方向变化不重要，也不能把所有联合校准方法判为无效。

下一步不将这组抵消现象直接改名为新算法。保留完整来源数据，重新筛选能提出独特、可部署干预的问题；成熟跨块重构、普通偏置及完整强基线仍是必须面对的对照。伪量化与 kernel 改进继续只计工程。
