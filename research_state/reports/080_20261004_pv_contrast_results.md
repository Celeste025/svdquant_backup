# 阶段报告080：PV双侧差分编码的首轮检验

2026-10-04，MiniMax-H3，E080 / C007。**结论：有局部对比误差改善，但强对照更好、总误差上升，停止当前编码版本，不进入视频或kernel开发。** 没有形成新方法收益或精细结构修复结论。

## 动机与假设

前轮拍手视频出现手指模糊/重复轮廓。假设是：P独立量化会损失相近概率的差别，进而损失局部输出对比。尝试在量化前把相邻key的P/V一起改写为和、差：

`Pa*Va + Pb*Vb = ((Pa+Pb)/2)*(Va+Vb) + ((Pa−Pb)/2)*(Va−Vb)`。

每32个原值变为16个和、16个差，仍用32个FP4值与2个group16 E4M3 scale。不以恒等式或一般差分保真认领创新；需要超过V中心化、仅P变换和普通重排的解释。

## 实验

固定现有SVDQuant＋官方SageAttention3基线。拍手两个seed各重放20步，捕获step14的block0、24；两条轨迹最终视频/音频latent均逐字节复现原基线。四组真实QKV，每组全部56 heads、完整21731 keys，视频规则网格36对相邻query，共72 query。不是手部人工ROI，不能直接当手指机制证据。

分别固定原QK和官方实际量化后的QK，比较原PV量化、V中心化32/128、仅P差分、双侧差分、随机配对及同预算只重排。中心化保留BF16均值并用未量化概率质量恢复，包含额外开销；它只是VC式中心化对照，不是完整VC聚类实现。完整32-key视频块才变换；665/10640对跨栅格行边界（6.25%），已如实计入。

指标是attention输出SSE及相邻query输出差分的SSE，相对同QK条件下的精确PV。以下是**局部误差变化，不是视频质量提升百分比**。

## 结果

block24、实际量化QK；负值表示误差下降：

| 表示 | 对比误差变化 seed0 / seed1 | 总输出误差变化 seed0 / seed1 |
|---|---:|---:|
| 双侧差分（想法1） | −14.29% / −13.30% | +6.23% / +5.57% |
| 同预算只重排 | −12.96% / −9.73% | −12.49% / −9.60% |
| V中心化32 | −30.31% / −31.04% | −40.24% / −42.07% |
| V中心化128 | −26.26% / −27.99% | −37.30% / −39.66% |
| 仅P差分 | −0.32% / +1.62% | +0.78% / +3.30% |
| 随机双侧配对 | −2.23% / −3.26% | +4.58% / +2.26% |

block0双侧差分的对比误差下降约9.2%，但总输出误差增加48.5%–56.7%。固定未量化QK时，block24对比误差下降11.4%/14.7%，总误差增加7.5%/4.5%，仍明显输给中心化；结论不是QK量化单独造成的。

实际QK下，双侧差分相对同预算重排仅额外减少1.54%/3.96%对比误差，未达到预设至少5%的优势，即使不计中心化的额外均值预算也未通过。若把QK误差纳入完整attention参考，block24双侧方案的对比误差改善仅3.43%/3.12%，总误差增加2.57%/2.34%。这仍是同一SVD轨迹上的局部attention参考，不是端到端BF16视频。

## 观察与判断

1. **“差分误差变小”不能等同“细节恢复”。** 双侧方案的差分投影增益并未更接近1：seed0从0.990916到0.990097，seed1从0.991645到0.990403；因此目前不能声称恢复了被压弱的对比幅值。
2. **此表示付出了邻居共同误差增大的代价。** 从保存输出事后分解 `共同项能量 = SSE − 差分SSE/2`，block24增加15.05%/13.83%，block0增加68.00%/58.73%。这是误差的代数分解，不证明P均值漂移、画面低频失真或模糊的因果来源。
3. **没有验证“P差分舍入是核心瓶颈”。** 仅P变换在block24几乎无效，普通重排接近双侧收益，V中心化更强。结果更支持先谨慎区分V表示/分组效应，而非认领新的P差分机制；也不能凭局部结果证明V中心化会改善最终视频。

按照执行前约定，当前版本停止；不扫group、层、步、head寻找阳性。若后续重开，必须提出同时保护共同项和差分、且无法由已有V中心化解释的新机制与可区分实验。C008本轮未执行。

## 2026-10-05 补充：停线范围与V中心化阳性结果

用户指出V中心化收益明显，不应连同双侧差分编码一起停止。原E080停止门槛针对C007双侧编码；上一轮沟通把“新方法未通过强对照”与“强对照不值得进一步验证”混在一起，现明确纠正。

V中心化32在block24的PV误差下降40.24%/42.07%、邻居差分误差下降30.31%/31.04%；block0的PV误差也下降61.99%/61.15%。把QK误差计入同输入完整attention参考，block24总误差仍下降15.43%/16.27%。这是值得跟进的局部阳性信号，不能因为它属于已有思路而否定其实际价值。

C007当前双侧表示继续停止；V中心化可作为已有方法/增强基线，下一步应以有限真实attention及视频验证判断局部收益能否迁移，并记录均值存储/补偿成本。当前没有端到端收益结论或新GPU任务。先验证有效性，再决定是否有区别于已有工作的研究问题，不先投入大规模kernel工程。

特别区分：当前center分支以量化前概率质量恢复块均值，收益不能全归因V残差范围缩小；它也避开了P量化质量误差乘块均值这一项。已有结果没有将两者贡献分开，不把该代数性质认领为新颖机制。
