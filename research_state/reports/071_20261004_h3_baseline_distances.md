# H3 SVDQuant baseline 与 BF16：LPIPS、L1、L2

2026-10-04。按用户决定，后续固定使用当前可用配方作为 SVDQuant baseline，不再为对齐官方默认校准配置扩大工程。既有实现与来源记录保留。

**10 条配对视频的等权均值：LPIPS-Alex = 0.4201，L1（MAE）= 0.1103，L2 的 RMSE = 0.1755；未归一化 L2 范数均值 = 2599.75，相对 L2 均值 = 0.5534。**

动机：用户需要量化基线相对 BF16 的直接视频距离。实验：复用 E010 的两例及 E038/E073 的四动作×两 seed，逐例核对实际噪声、文本嵌入、时间表和生成／解码设置，20 个 MP4 的 SHA 与记录一致。没有新生成、训练或校准。

基线为 200 个主干线性层的原生 NVFP4 W4A4＋BF16 rank-32 低秩分支；attention 保持 BF16。参考为同一 H3 的完整 BF16 路径。E038 的 bf16 标签仅指 attention，本次未误用为完整 BF16 参考。

计算口径：全部 124 帧、1024×576 原尺寸，解码 MP4 为 RGB；不缩放、裁剪或配准，不计算音频。令像素归一化至 [0,1]，N=T×H×W×3=219,414,528：

- LPIPS：TorchMetrics 1.9.0 的预训练 AlexNet 实现，FP32，normalize=True，逐帧取均值。
- L1（MAE）：Σ|预测−参考| / N。
- L2 范数：√Σ(预测−参考)²；随分辨率和视频长度变化。
- L2（RMSE）：L2 范数 / √N，便于与 L1 比较。
- 相对 L2：L2(预测−参考) / L2(参考)。
