# 阶段068：先检查缺陷，再决定是否值得实现干预

2026-10-04。遵照控制工程投入的要求，本轮没有新增实验代码、模型调用或 GPU 实验。两个子 agent 分别提出候选、检查替代解释；root 查看既有媒体。**“动作相位保留而手部边界变差”仍是有效线索，但尚没有足够证据把它解释为接触后的身份混淆。暂不开发相应 attention 干预。**

## 动机 / 观察

E041 拍手片中，低位 attention 下的开合轮廓仍在变化，手指却更难辨认。候选假设是：外观相似的两只手靠近、遮挡再分离时，量化使跨帧对应从同一只手转移到另一只手，保留周期却混合身份。竞争解释是单帧几何、纹理或解码已经损坏，并不需要身份交换。

这个问题针对 E038 的 **attention 精度变化**：三臂共享 native SVD 线性层，“bf16”仅指 attention。不能用它直接解释 W4A4 主干两种校准配方的 SSE 排序，也不能把通用 attention 排名保护当成新方法。[独立候选与近邻](../02_signals/h3_independent_reset_20261004.md)、[反方与最小对照](../02_problems/h3_action_readability_screen_20261004.md)分别记录了 DiffTrack、QuantWM、VC-Attention 等边界。

## 结果 / 结论与下一步

1. **不为该窄假设开发 P 权重交换、对象 mask 或新 kernel。** 目前更经济的解释仍包括持续的单帧几何/纹理损坏。H3 双向 attention 可以让早期视频帧受后面 token 影响，所以早帧已有重影并不否定广义时空对应错误。
2. 候选保留为待识别的问题，不登记机制阳性或方法创新。正确身份交换与等扰动 sham 的诊断思路已保存；只有出现可追踪的身份转折，才值得实施。普通 QK/PV 精度消融即使执行，也只算归因工具。
3. 时间压缩 / decoder 解释与之前的只读记录重合，不重新包装成新方向。四倍时间压缩也不意味着输出运动有简单的3 Hz上限，子帧信息可以在通道中编码。[既有 decoder 边界](../01_literature/decoder_quantization_prior_review.md)
4. 后续优先寻找能明确区分竞争解释的观察或小实验，不继续围绕这几张手部图扩文献和造工具。E072a及完整基线工程继续搁置；已有有效实现可用于探索。E068人评仍待，未读取私有映射或伪造质量结论。

本轮价值是收紧了一个候选的证据要求，并据真实媒体决定暂不投入干预工程；没有新生成实验结果或可投稿贡献。
