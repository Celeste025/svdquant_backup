# 013：普通 NVFP4 更快，但与 SVD 配方存在真实误差取舍

2026-10-02，E014。**补齐完整模型对照后，没有单一赢家：普通 NVFP4 比现有 SVD 配方少14.4%的 DiT 延迟，但视频/音频误差随输入交叉。保留两套基线，不把删除低秩分支当作新方法。** 当前仍未形成顶会贡献。

## 本轮做了什么

从本地原始 BF16 H3 重新导出200个主干线性层，构成无平滑、无低秩分支的 `plain_h3_recipe`；与 BF16、现有 smooth+rank32 SVD 配方比较。两量化臂使用相同 group16、E4M3 scale、原H3 signed E2M1 ties-lower 配方和原生 SM120 FP4 GEMM。其余张量保留原精度，包括 FP32 time/RoPE。比较的是整套配方，不能把差异单独归因于 LR，也不称标准全RNE最优PTQ。

固定三个已经保存的真实共同状态：旧校准 p1/step0，E010 BF16轨迹 p30/step5、p36/step14。后两例虽不在旧校准集，但已经看过，只作诊断。没有训练、调参或追加视频。

## 结果

相对同输入 BF16 输出的 NMSE，由原始完整输出在 CPU 用 FP64 独立累计；越低表示固定状态的数值重建越好，**不等于生成质量**。

| 状态 | 模态 | SVD 配方 | 普通 NVFP4 | 普通/SVD |
|---|---|---:|---:|---:|
| p1 / s0 | 视频 | 0.023338 | 0.047532 | 2.037 |
| p1 / s0 | 音频 | 0.041689 | 0.036221 | 0.869 |
| p30 / s5 | 视频 | 0.065412 | 0.055588 | 0.850 |
| p30 / s5 | 音频 | 0.102239 | 0.165755 | 1.621 |
| p36 / s14 | 视频 | 0.012059 | 0.012043 | 0.999 |
| p36 / s14 | 音频 | 0.014027 | 0.015151 | 1.080 |

SVD在p1的视频输出有明显收益，p30的视频输出却更差；p1/p30音频排序又与视频相反。p36视频几乎相同。这里prompt和step同时变化，不能推导时间规律或总体质量排序。此前局部 block0 实验不能替代本次完整200层对照。

同一空闲 GPU5、每臂独立进程，固定p1原形状，1次warmup＋3次repeat＋1次独立profile：

| 指标 | BF16 | SVD 配方 | 普通 NVFP4 |
|---|---:|---:|---:|
| 完整 DiT 中位耗时 / s | 8.291 | 6.804 | 5.823 |
| 三次耗时范围 / s | 8.260–8.316 | 6.785–6.814 | 5.809–5.833 |
| 模型常驻 storage / GiB | 37.46 | 11.95 | 11.67 |
| 稳态前向峰值 allocated / GiB | 40.86 | 16.81 | 15.06 |
| 稳态峰值 reserved / GiB | 42.94 | 30.23 | 27.35 |
| 当前加载器启动峰值 allocated / GiB | 37.54 | 37.60 | 37.60 |

普通配方相对BF16为1.424× DiT加速，相对当前SVD为1.169×；这是既有方法的工程基线结果。计时包括在线pack，检查flags在计时后统一验证；含检查的host中位分别8.292/6.804/5.823s，差别不足0.4ms。输出拷贝/hash、加载、TE、sampler、VAE不在计时内，不能称完整生成加速或质量等价加速。启动仍先载BF16，37.6GiB不是直接packed加载的必要成本；当前SVD也不是已充分融合的部署上限。

独立profile中普通配方的BF16 attention仍占kernel工作量58.7%（3.415s），SVD为49.4%。这说明只继续删减linear开销会受限；它不是新瓶颈理论，也不能把kernel时间占比当端到端可得加速。

## 验证与运行记录

两个CPU预检通过、34份源码/协议冻结。全部200个原W packet解码与独立软件QDQ数值精确一致，原W来源逐层绑定；四种线性形状的同packet native算术检查通过。BF16三状态raw输出精确重放历史结果，E010两状态的scheduler velocity也逐元素、逐byte一致；三臂实际输入签名相同。量化evaluate/profile每次200 FP4 GEMM＋102 BF16 SDPA、200合法域检查、0磁盘加载；非目标张量身份保持。每臂warmup、三次repeat和profile输出均与自身evaluate SHA一致。

总计24次完整DiT，总墙钟624.7秒，包含导出、加载和一次调度暂停；不是性能分母。原调度器在上一进程退出后读到GPU5显存0、利用率13%的尾采样而停止。确认无其他进程后，以独立冻结的续跑器要求两次稳定空闲读数，沿用原45分钟截止，未重跑或覆盖结果。原失败记录保留。

独立CPU审查已完成：269个文件校验，200份原W共192.676亿元素的来源SHA逐层重算；原bias、三臂原输入与真实DiT packing、raw/velocity符号布局、FP64误差、全部bench输出/计时/调度链通过。CPU耗时32.7秒，未初始化CUDA。权重数学roundtrip继承冻结GPU导出器的独立QDQ/decoder证据，不声称在CPU重复量化全部权重。[独立汇总](../../results/research/E014/independent_summary.json)（SHA `b5cf4dc298d1d5409942bc96a1276be98d6171bf98909fa1699864a1f7adb460`）。

## 结论与下一步

这次补的是必要强基线，不是“NVFP4不需要SVD”的论文发现。SVDQuant原文已有NVFP4有无LR消融，JustQuant已有训练后移除额外分支的路线；本结果也没有证明无训练plain质量足够。[流程与近邻核查](../00_state/phase4_process_critique.md)

后续保留两臂，不再用单一局部NMSE选配方。优先区分两种可核查问题：跨模态误差是否通过联合去噪轨迹产生非对称传播，以及现成低位attention的完整模型成本—保真取舍。前者先做近邻和已有轨迹核查，尚未观察到机制；后者先比较成熟基线，不开发新kernel凑贡献。不会因这三组交叉就扫rank、换一套加权loss或扩大生成样本追求阳性。少步模型已有DMD/QAD分布目标，单纯从逐步误差改为分布目标也不是新意。[少步机会审查](../01_literature/phase4_fewstep_opportunity_review.md)
