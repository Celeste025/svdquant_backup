# E041：既有拍手媒体的动作可辨性诊断

2026-10-03，探索性、CPU媒体检查，无新生成/评分/GPU。E038固定native SVD线性权重，仅BF16/global/coarse16 attention变化；既有16个FP4-vs-BF16配对的RAFT均值全部下降，14对前三中后三段均下降。但各自由轨迹构图/主体尺度/纹理不同，不能直接推运动损失，也不恢复已被E022否决的QAD运动收缩主张。

本轮只解决更低层的读出问题：在两个seed的全部六条拍手视频中，FP4是否仍有可辨的手部开合周期，还是主要出现纹理/重影使运动不可读？选拍手因为它是既定四题中有重复事件的动作，不以分数或生成好看与否选seed/arm。其余18条不删除、不重打分，其光流不作空间因果解释。

使用原24fps、全部124帧，不降帧率；生成逐帧联系图仅辅助判读，原MP4完整保留。两位agent分别检查一个seed的全部三臂（已知项目背景，非正式盲评）；root综合。不得用8帧旧联系图数周期，不得声称已实时播放完整视频。完整帧检查也不能确认亚帧或三维接触。

区分张开→闭合→再张开的完整可辨周期与视觉可确认接触。每项记录前后张开证据帧、闭合区间[start,end]、接触confirmed/uncertain；投影重叠不等于真实触碰。重影、两手身份不明、遮挡、切镜/画外记录不可读区间，不猜事件也不当零动作。片头/片尾半周期单列。

仅在连续可读窗口且至少两个完整周期时报告频率，保留事件区间；不可读窗口不得拼接，不用全视频时长把频率压低。若只有下界，写至少n次、其余不可判，不伪造单点总数。记录背景相机变化和主体尺度，但近景不强造肩宽比或推算速度。

停止/继续：若主要是可读性下降或数量/频率不一致，不提出统一动作变慢机制。若两seed都能明确读出同方向动作变化，才将其作为窄的后续因果问题，并先面对现有低位attention/Temporal KV方法，仍不直接构建新loss。有限媒体诊断本身不是论文贡献。
