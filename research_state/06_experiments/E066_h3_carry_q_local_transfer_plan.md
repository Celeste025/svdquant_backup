# E066 — carry-Q 局部优势在既定诊断输入上的迁移

2026-10-04。执行前计划；baseline diagnosis / exploration，无新方法claim。

## 动机 / 观察 → 问题

E065/b 已经独立核验：carry 相比 restart 在200层、1600个校准格的选中局部SSE均更低，层中位下降3.02%；但四个既定teacher输入的完整video SSE均上升。校准prompt/状态与这四点不同，因此还不能把反转归因深度传播或模态竞争。

**H1（输入迁移不足）**：在这四个未参与本次候选选择的teacher输入上，保持原M512评分形状的局部比较已出现反转。
**H2（局部优势保留）**：相同输入的局部误差仍改善，反转出现在局部SSE与整模video读出的关系中。输出敏感方向、功能度量、student输入变化及组合效应均仍可能；本实验不区分它们。

**决策价值**：决定下一步首先核查普通校准覆盖，还是有必要研究局部指标与模型组合的关系。一般校准迁移或层间联合校准已有大量先例；本次诊断自身不构成创新。E064只保存两个状态×五个block，不能替代对全部200层×四点的核验。

## 最小有效实验

冻结E065b最终restart/carry各200层的selected导出，不拟合、不选新候选、不改smooth/rank/量化器/种子。四输入固定为原p30 s5/s6、p36 s14/s15，完整DiT的实际输入必须与E065b/历史BF16对应输入相同；两个量化臂的整模输出直接复用已完成的E065b，不再次执行。

只运行 **4次完整BF16 DiT**。每个目标linear：

1. pre-hook固定真实BF16输入，计算相同smooth后的 `xs=x/s`，对**全部M行**只打包一次。两臂共用该实际NVFP4 packet/global/SF；512行抽样不参与主计算。
2. post-hook取得原始完整M的BF16输出作为teacher target；分别加载本层两份已选native导出，在同一full-M packet与未量化xs上执行主GEMM、两次BF16低秩GEMM及原BF16相加。每臂计算完成立即释放完整输出/branch/module，再处理另一臂；不让两整份量化模型与BF16整模同时驻留。
3. 分块（至多2048行）计算FP64每行误差平方和与teacher能量，保存CPU per-row向量。主读出只包含实际位置映射中的**非padding行**，video单列；同时保留audio/text与joint，不以模态平均权重替换原比较。所有真实行均计算，因此主指标没有M512 GEMM或漏采token混杂。
4. 另按E065同一确定性规则，从排序后的有效联合域抽512行，保存xs、实际packet切片/原global、teacher输出、两臂**full-M输出的对应行**及真实模态indices。每臂释放完整输出后，用同一模块、同一packet的512行切片和xs子集再执行一次原E065公式，保存真实M512输出；不重新量化512行。`metrics`为full-M全部有效行，`sample_metrics`为full-M输出的512行，`subset_metrics`为真实M512输出对同一BF16目标512行的误差。三者分别支持全行读出、抽样覆盖和GEMM形状对照。
5. hook不替换原BF16输出。完整BF16实际输入、raw输出及velocity必须逐byte复现既有历史；每次应有102个SDPA、200次full-input pack、800次局部native（400full-M＋400M512）、0次disk offload。四次总计408 SDPA、800 pack、3200 native（1600＋1600）。导出加载的普通文件I/O单独允许，不冒充模型disk offload。

不保存全部full-M矩阵（预计TB级），不作自由轨迹生成、TE/VAE、MJ、新训练或新的量化整模调用。只统计原始SSE，不以新中心化/归一化损失选择结果。模型、数据、导出、源文件与已完成独立检查均绑定到SHA；代码沿用现有纯helper与native算子，不修改已执行E065源/产物。

## 读出与预先规定的解释

逐点报告200层full-valid及video的carry/restart SSE比率、改善/反转/相等计数、层内比率中位数与范围；按四种linear类型分组。不同层的未归一化SSE不直接相加作为模型总体损伤。若分母为0，保存原SSE并单列，不加任意epsilon制造排序。

保存真实M512与full-M同512样本的比率，前者与E065校准M512准则对齐，用于判断输入迁移；两者差异用于检查矩阵形状影响；full-M抽样与full-M全行的差异用于检查token覆盖。它们不能倒推原校准全token损失。audio/text使用全真实域作为主读出，不把少量512样本的模态分数当主证据。四点已被反复观察，仅相对候选选择heldout，不是新的质量盲测。

M形状对照同时改变native主支和两次BF16低秩GEMM，测量的是整个线性层实现的形状算术效应，不能只归因FP4主kernel。

- 若真实M512出现广泛局部反转，说明原校准准则的收益未迁移到这些输入；优先定位普通覆盖/目标问题。若仅full-M反转，先检查同512行的形状差异和全行覆盖差异，不能直接归因输入迁移。即使出现某个很差层，也不能据其SSE直接声称它导致整模恶化。
- 若局部优势在四点全部200层的video域仍保留，则可排除这些输入上的简单局部SSE排序反转；仍不能直接命名为跨层干扰、传播放大或模态竞争。
- 若混合，逐层/类型如实记录。少数改善不代表覆盖整体良好，少数反转也不证明它们解释了全部整模差异；不事后挑“敏感层”做恢复网格。
- 不论哪种结果，都不自动增加迭代、开新loss或认领机制。结果必须先改变一个具体后续问题，才分配新的模型实验。

## 独立复核与边界

CPU检查最终manifest到每层selected导出的身份、四teacher输入身份/位置域和实际样本规则，0CUDA/0forward。GPU输出冻结后，独立NumPy复算两臂full-M样本和真实M512保存矩阵的SSE，前者核对相应per-row数值；再按完整真实模态indices重新归约全部保存的per-row向量，并复核完整BF16输出/输入身份。

**不声称独立逐channel复算未保存的其余行，也不声称重新执行native kernel。** 完整行SSE依赖公开冻结runner的分块FP64归约，独立检查覆盖其全部行归约、全层样本算术与来源身份。该限制应进入最终报告。
