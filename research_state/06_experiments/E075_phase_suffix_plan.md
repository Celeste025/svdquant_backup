# E075：近等局部误差能量的相位干预与共同续跑

模式：探索。用户授权继续报告072相关研究；现有SVDQuant基线冻结。

问题与假设：E018同输入下，block24两种query分组相位的局部SSE仅差约0.062%，但误差向量明显改变。这种结构变化在一次实际部署调用后是否足以造成可辨视频差异？竞争解释是后续传播抹去差异，或只产生允许的构图/内容变化。不能预设重影、闪烁或质量改善。

固定协议：只用已有p36/seed59526，E017 block_mean轨迹s14起点，block24（此前预选0/24/48的中点）。复用E018已执行原生算子的逆置换输出；替换video latent帧2..34、原packed rows2379:21387，其余text/audio、首尾、padding均保留原输出。先验证同参考的内区SSE差<1%、phase128内区逐字节相同；不重新挑层/相位。

四臂：原相位phase0续跑s14–19；phase128仅s14一次作为完整输出逐字节一致控制；phase64仅s14/block24替换后续跑6步；BF16 oracle只在同一位置同一区域换成保存的BF16 attention输出并续跑6步。每臂在替换前验证实时Q/K/V与E018相同；原相位逐步预测/更新和终态均须精确复现E017。总计19DiT；只为phase64/oracle解码2条视频，原相位复用终态精确相同的历史视频。

该masked替换是局部因果诊断，不是可部署完整相位算法。近等SSE仅在attention输出成立，不外推out_proj重新A4、完整DiT或轨迹；oracle不是完整BF16模型。固定原20步时间表、CFG1、双模态更新、原VAE。保留全部结果，不修改已执行E017/E018源或数据。

读出：保存实际局部误差、每步差异及终态；查看最终视频固定联系图与必要相邻帧，以花瓣/木片轮廓可辨性、产品/文字稳定性为探索读出，允许unknown。透明液体、淡出、允许的花形/构图变化不能算功能损伤。LPIPS/MAE/RMSE只描述差异，不替代功能判断。

决策：若oracle也无可辨影响，本次单层单步窗口缺少可见作用，停止此窗口；若oracle有效但相位无稳定功能差异，不扩相位/层/步网格；若相位对缺陷有可辨作用，仅保留候选，需新输入确认后才讨论方法。无结果自动触发校准、训练、kernel或全模型随机化。

预算：GPU0单卡，生成与解码共享1200秒/60GiB allocated，最大19DiT、2video+2audio VAE，新数据<2GiB。CPU先做输入/缓存/mask核验；故障记录保留、不自动重跑GPU。
