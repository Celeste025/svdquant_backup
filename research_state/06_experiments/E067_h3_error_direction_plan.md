# E067 — carry/restart 保存误差的幅度与方向

2026-10-04；执行前协议，exploration / descriptive，0 GPU / 0 forward。

## 动机与具体问题

E066 已排除四个 teacher 状态上 video 局部排序反转和形状/采样排序假象。它没有保存 full-M 全通道误差向量，也没有识别整模反转原因。当前仍可能误用一个简单模型：carry 主要沿原方向缩小各层误差。因此先用已存样本检查这个模型，不重新采集、不根据局部相关性提出新方法。

Hradial：本次候选变化 δ=eC−eR 主要是原误差 eR 的径向收缩；Hdirection：变化主要包含与 eR 正交的分量。二者只描述保存的 teacher 局部向量，均不意味着对应整模因果解释。

## 最小有效设置与读出

读取 E066 全部四状态×200层的既定样本，以及 E065b 的四点完整两臂/teacher输出。首先验证完成报告、独立复核、输入与输出文件身份，不修改它们。局部主域为固定512联合样本中的video行，另列joint；不把新方向统计称为全token结果。完整DiT统计使用保存velocity的全部video/audio元素，不能把它当自由生成轨迹或质量读出。

令 eR=yR−yB、eC=yC−yB，计算：

- ER、EC、ρ=<eC,eR>/ER、cosine；ρ保留符号，零分母单列。
- 直接形成 u=eC−ρeR，计算 ||u||²，不靠大数相减得到它。
- δ=eC−eR，计算 ||δ||²、径向变化能量(ρ−1)²ER、正交变化能量||u||²，以及后者占||δ||²的比例。
- 检查 EC=ρ²ER+||u||²、||δ||²=(ρ−1)²ER+||u||²、<u,eR>=0，原raw SSE复现E066独立统计。未定义的除法保持null，不加epsilon制造方向。

raw为主；固定投影去除每个通道在相应行域的均值作为控制，两臂使用相同投影，不据投影挑结论。full-M保存样本与真实M512分别计算上述几何；另直接计算两种形状的δ差异能量/||δ_full-M||²，作为同权重形状算术控制。不是新kernel诊断。

报告全部层的分布/类型分组，不跨层累加不同单位的原始SSE；“正交占本次变化一半以上”的计数只解释变化由哪一部分主导，不是显著性或论文晋级阈值。无需重复800层source核验之外的模型权重加载。

## 决策与不可作出的推论

若主要近似径向且ρ在[0,1]，撤销“候选引入新方向”的动机；若主要非径向并明显超过同权重形状控制，仅确认不宜用单纯缩幅近似，不自动启动GPU、功能loss或方向约束训练。混合则如实分层报告，不选敏感层追阳性。下一GPU仍需可干预且会改变方法选择的排他预测。

两层标量误差1与−0.99分别乘0.99与0.98，局部误差都下降，和却由0.01增至0.0198。故即使纯径向收缩也可能减弱抵消；非径向也不等于有害。样本几何更不能证明视频特有、NVFP4特有或可投稿贡献。普通PTQ的候选差异可能完全解释该现象。
