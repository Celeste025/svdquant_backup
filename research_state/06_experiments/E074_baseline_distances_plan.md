# E074：现有 H3 SVDQuant baseline 与 BF16 的视频距离

用户指定现有可用配方作为后续 SVDQuant 比较基线，不再为对齐官方默认配置扩大校准。保留原实现来源记录，不改变历史实验身份。

目的：直接报告已有配对视频的 LPIPS、L1、L2，不检验新方法假设，不生成新视频、不做 PTQ。

固定样本：E010 中文文字、产品展示各1例；E038 主干 SVDQuant＋BF16 attention 的4动作×2seed，与 E073 完整BF16配对，共10例。实际噪声、文本嵌入、时间表、生成/解码设置及媒体SHA匹配后才评分，不读取E068匿名映射。

指标：全部124帧、1024×576原尺寸RGB，无缩放/裁剪/配准。LPIPS-AlexNet为预训练TorchMetrics实现，FP32，[0,1]输入由normalize=True转换；逐帧取均值。L1=MAE；L2同时保存原始范数、RMSE及相对参考的范数比。像素差用uint8转int32，精确int64累加；统一换算至[0,1]。各视频等权，另列8动作组与2旧样例，音频不评分。

资源：GPU0上已安装环境和已缓存AlexNet，无安装下载；单进程，1200秒上限。每例首帧自比较LPIPS应近零；尺寸/帧数/配对不一致立即失败，不跳过样例。正常预期仅需数分钟。保存逐帧、逐例与汇总数据，完成后复算归约，不追加生成/参数网格。
