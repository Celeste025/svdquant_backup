# H3 帧间弱变化假设：四篇最近邻碰撞与反例

2026-10-04。E072a 已按用户意见停止；本代理未创建/执行 E072a checker。此处是新问题的有界反方核查，0 GPU、0 新实验代码，仅四篇 primary；没有本地阳性，没有新方法或创新认领。

**一般的“视频量化要保护运动/时间一致性”“给低秩补偿加 temporal loss”“公共特征高精度、差分低精度”均已有直接先例。** 尚可检验的窄问题是：在真实 H3 中，低精度是否对任务相关的弱帧间变化产生有符号、可干预的选择性衰减，而非普通小分母效应、空间细节模糊、相位偏移或新增闪烁。现有 E041/E067 都没有证明这一点，也没有排除它。当前不值得直接训练一个 temporal loss；值得先做一次能区分这些解释的短诊断。

这是四篇碰撞，不是“已穷尽所有 motion-aware PTQ/QAT”。具体帧差损失的每一种形式未逐式查全，因而不报“无人做过”；但通用时间关系蒸馏、时空公共分量/残差和低秩量化补偿已足以否定靠重命名立新意。

**最强的反例不需要先跑模型。** 令 `d_B=D_f Y_B` 是同一输入下 teacher 输出的帧差，`e=Y_Q−Y_B`。普通、零均值且与 teacher 无关的噪声会令 `||D_f e||²/||d_B||²` 在弱变化区域变大，却不导致有符号增益 `g=<D_f Y_Q,d_B>/||d_B||²` 的期望小于1。因此“差分相对MSE更大”可能只是分母小，不能叫选择性抹除。静态/零差分分母必须单列，不加epsilon制造比值。

第二，若人物运动位移保持不变、只把画面作空间模糊，小位移下的图像差分约为 `∇I·u`；模糊降低梯度，也降低帧差和估计光流，动作频率仍可相同。第三，纯时间相位平移可使与原运动方向的投影下降，而运动幅度未降低。第四，差分能量变大可能来自闪烁，不能叫运动保留更好。固定像素/latent 网格上的 temporal residual 包含外观变化、遮挡、相机运动与噪声，本身不是“运动真值”。

NVFP4 分组的概念风险也要保留：若一段弱变化得到自己的动态尺度，它不必因绝对幅度小而丢失；需要证明的是它与哪个公共幅度/离群量**共享了有效量化分辨率**。线性层的逐行量化本身不认识视频帧的语义标签；只观察时间差高误差，可能只是一般低幅度对比度问题，而不是视频特有机制。这里没有据此要求先证明新意才能诊断。

最小有效鉴别应回答一个选择：继续追“有符号运动响应衰减”，还是转为普通噪声/可读性问题。无需再造完整校准器。

1. **已有缓存的必要读出。** 预先固定两个相同 teacher 输入的完整视频输出状态，采用已冻结量化臂，不选差异最大的层/帧。按真实 frame layout，固定同一帧差算子 `D_f`，另用保留同形状的帧均值投影 `P_0`。帧均值仅是不随帧变化的分量，不是纯 appearance，余项也不是纯 motion。报告实际帧差能量、signed gain `g`、直接计算的正交项 `r=D_f Y_Q−g d_B`，以及 appearance 投影的相应量。阈值按 teacher 信号定义，弱信号桶不由量化误差筛选；保留所有预选帧。若使用 denoiser velocity 或含噪 hidden state，只称“帧轴响应”，不能称已测得语义运动。必要时按原 scheduler 定义还原同状态 clean 预测，并明确它仍只是预测。
2. **同一CPU读出必须放入两个反例控制。** 对 teacher 加入与观察误差同能量的零均值扰动，检验归一化帧差指标是否自动报“弱运动损伤”；对已有 teacher 媒体作固定空间模糊或轻微相位平移，检查读出能否区分细节/相位与幅度。它们是测量控制，不是生成干预或新方法；若控制也触发同结论，应停止把该读出解释为运动抹除。不要只用 RAFT 总流量或 temporal smoothness 排名。
3. **若要称机制，最小因果对照是有限响应，不是再加一个相关图。** 固定同一真实状态/同一模块，使用同幅度的 motion-aligned 小扰动与空间细节方向控制，各自比较 BF16 和已冻结 native 量化函数的有限差分响应；方向需由独立 teacher/已有轨迹规定，不能从量化误差反推。原输入是共同基点，按 BF16 响应归一并分别记录量化尺度变化，避免“运动方向本来更弱”造成假象。一个预定幅度即可，不扫描epsilon寻阳性。只有真实时间对应方向相对等幅、等组尺度条件的普通空间方向仍有额外衰减，才值得继续定位；反之是一般小信号量化/空间细节问题。此处仅提出合同，没有写代码或申请执行。

第1–2项能否实施取决于现有缓存确实保留完整帧布局；不能拿 E067 的稀疏512行去拼相邻帧。即使必要读出阳性，也不能自动训练 loss、调整 rank、重启大GPU工程或认领创新；第3项的功能差异与最终动作可读性还需连接。若最终可行方法只是公共项高精度加delta低精度，应直接以 DeltaQuant/ResQ 为邻近方法；若只是 teacher temporal关系蒸馏，应直接以 Q-VDiT 为近邻。剩余空间要由一个具体失败条件、排他预测及部署代价来界定，目前尚未建立。
