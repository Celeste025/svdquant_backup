# H3两个attention候选的直接近邻排除

2026-10-04。用户要求回到创新假设后，root做有界定向检索与primary阅读，未开GPU、未实现方法。以下是候选否决，不是本地机制观察。

1. **可融合的RoPE相位自由度。** 原设想是共同2×2旋转Q/K，保持精确attention不变，同时改善低位表示并融合到RoPE。[RotateAttention，2607.02584v1 §4.1，式7、9–10](https://arxiv.org/html/2607.02584v1#S4.SS1)已明确给出可融合块对角2×2旋转及其可学习版本。全局位置原点/相位旋转属于更小的自由度；从INT4换NVFP4不足以避开这个直接覆盖。停止，不做kernel或GPU验证。这里不评价其性能声明，也不声称所有RoPE相关问题已解决。

2. **量化logit方差引起softmax偏置。** 原设想是低位误差通过指数凸性系统性改变attention质量分配，而非只有零均值扰动。[Quantized Keys Steal Attention，2605.26266v1](https://arxiv.org/abs/2605.26266)已研究视频KV量化的Jensen偏置，并给出按量化步长和query范数计算的修正。本轮读其官方摘要，足以排除通用Jensen修正作为新核心；未读全文逐式核查，也不将其KV缓存结果直接视作H3同时W/A量化的实测。若要继续，必须先有超出这类已知偏置的具体现象与预测，当前没有。

结论：两个通用出口均不立claim，不扩大文献扫描，不花GPU复现它们来包装创新。
