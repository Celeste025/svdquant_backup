# H3 研究投入重排：本轮不新增机制实验

2026-10-04。按用户最新指令停止 E072a 工程；本 agent 尚未创建其 runner，0 CPUcheck / 0 GPU / 0 新 SVD。本页仅阅读既有 signal/problem/claim、报告049与060–063及结构记录；未读新代码、未分析新张量。使用 problem-formulation，未修改共享 state。**建议保留的新机制假设：0 个。** 以下记录唯一达到具体结构层的候选及其退出理由，不用方向清单填数量。

**证据首先限制了问题。** E065b/E066 已证实固定两配方在四个 teacher 状态的全部800个层×状态 video 局部 SSE 排序一致，整模 SSE 相反；E067 进一步排除了保存样本上的简单径向缩幅。它们没有识别有害误差方向、量化胞元跳变或生成质量损伤。E068 完整视频已生成，但人评未判定。这组观察不能单独支持新增方向损失、联合校准或跨步配额；ARHQ、QDrop和跨层补偿的精确边界已在既有记录中展开，本轮不换名重开。

**唯一具体假设：确定性调制坐标是否被当作数据激活反复量化，挤占了有限高精度保护？** [既有结构审计](../00_state/phase2_systems_feasibility.md)证实，本机 H3 的 AdaLN shift 来自8维时间表的仿射投影，每模态 shift 族至多9维，三模态联合至多27维；qkv/fc1 输入形如 `X = norm(H)·D(t,m) + β(t,m)`。因此可以精確分离 `XWᵀ = (X−β)Wᵀ + βWᵀ`，将已知调制项的输出放在小型高精度表或系数表示中，再让原生 A4 处理内容项。这是结构事实，不是已观察到 H3 的主要量化损伤，也不意味着乘性项 `W·D(t,m)` 是低秩。

可区分预测原本是：在留出输入上，去掉 β 后的真实 packet 改变能带来超出普通输出 bias 校正的收益；收益取决于正确的 `(t,m)` 调制坐标，而不是任意同范数中心或激活中位数。最强替代解释是普通不对称分布中心化、时间条件 bias 修正，或者 β 的影响很小，rank32本已覆盖有用方向。单独测出 β 能量大、移除后 MSE 小，都不能区分这些解释。

**直接近邻使这个出口目前不足以立项。** 本轮两条定向查询后读取 [HTG，arXiv:2503.06930，§4.1 Eq.5、§4.3](https://arxiv.org/html/2503.06930v1)：其方法已用随时间变化的通道 shift，保存对应 `zW` 输出 bias，并将移位与缩放吸收到 AdaLN。这里改用模型给定 β、压缩成27维或换 NVFP4，并没有改变核心表示与补偿代数。HTG 的实际选择规则、INT量化和本机 native 合同并不相同，不能宣称它已经测过本题；但目前也没有一个必须依靠新方法才能解决的存储、算力或信息约束。已知低秩预算与移位相加，不能因此称为新的保护机制。

另外读了 [EMA / Awakening Diffusion Transformers，arXiv:2607.02968，§IV–V](https://arxiv.org/html/2607.02968v1)：它已有 AdaLN 相关大激活与细节生成的干预分析。它没有直接覆盖 NVFP4 量化，但“这些通道可能影响细节”不能再充当新的机制终点。[HadaNorm](https://openreview.net/pdf?id=KrhQ8dFSQ5)全文被验证页阻挡，本页不根据摘要认定其精确覆盖范围。没有继续扩大检索。

**若将来有额外证据使该假设重新值得投入，一次会直接杀死它的实验是什么？** 固定预选 qkv/fc1、既有两种不同提示的完整输入和同一 native 权重/支路预算，只比较模型 β 的解析移出、同字节预算的 HTG 式时间中心、普通输出 bias 校正；各臂须从各自完整输入重新打包，并保留 BF16 仿射重排的数值控制。用未参与中心估计的提示判别，不能在两个提示上同时拟合与评价。若 HTG 中心或普通 bias 已解释解析移出的收益，或剩余效应不超过实际重排舍入与留出差异，即停止这个结构机制；不换层/时刻寻找阳性。**目前不建议执行**：即使解析 β 获胜，本页仍缺少它为何超出已有时变 shift 表示的具体方法约束，所得首先只是基线选择结果。

**下一次研究实验的决策。** 不用 E072a 停止省下的预算再开一个已知代数的 oracle，也不等强基线完整复现才允许构思。现有最有价值的未决证据是已交付 E068 的任务读出：若质量与 SSE 排序不同，应停止修复该 SSE 反转；若出现一致、可指认的缺陷，再围绕那个实际缺陷提出带匹配控制的机制干预。人评本身不是创新或机制证明，也不将等待视为实验结果。本轮缺的是具体可区分因果预测及其部署后果，不是更多层数、校准样本或复核工具；未新增 claim，未安排 GPU。
