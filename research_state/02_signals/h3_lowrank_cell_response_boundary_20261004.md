# H3：低秩支路与 NVFP4 胞元内响应的精确边界

2026-10-04。独立一页筛查；仅关键词查重并读取三份直接相关 note，0 GPU、0 模型/实验代码执行、0 新方法候选。**保留一个条件性机制问题，不建议立即做静态 code 计数或 SSE 代理实验。**

**候选问题。** NVFP4 微尺度为 E4M3，而 SVDQuant 的 rank32 支路读取 BF16 输入。当一部分实际输入变化尚未改变低位离散表示时，高精度支路是否成为这些变化的主要通道；它保护的方向与最终任务需要的方向是否错配？这比泛称“噪声越小越难量化”具体，但尚无观察支持。它不是 global-scale phase、深度放大或新 Jacobian loss。

**先把代数写对。** 令平滑后输入 `X∈R^(N×d)`，固定残余权重 `R` 与 rank32 矩阵 `L`，忽略舍入的 shadow 算子为 `F(X)=Q_A(X)Rᵀ+XLᵀ`。在全部 E2M1 codes、E4M3 scales、amax 符号/索引不变的开区间内，`Q_A(X)=g(X)C`，其中 C 固定。因此

`dF = dg·(CRᵀ) + dX·Lᵀ`。

单 token 输入到该 token 输出的 Jacobian 上界是 `rank(L)+1≤33`；若该 token 不决定全局 amax，global 项对它的自导数还可为零。**整个矩阵展平后的上界是 `N·rank(L)+1`，不是 33**，因为 LR 在 N 个 token 上分别作用。即使该局部公式成立，block 的残差 identity 也不受这个秩上界约束；不能推出完整 denoiser 只有 33 个响应方向。

**为什么这还不是一个有效实验动机。** 实际输入与 LR 计算均为 BF16，没有任意小的连续扰动。长序列里任一坐标过界就离开上述全 tensor 胞元；正常去噪步可能跨过许多胞元。反过来，仅有很多微块不换码也不等于它们承载了重要输入变化。归一化/AdaLN 还使“扩散 sigma 变小”不等于实际 linear 输入幅度或更新变小。局部秩定理没有自行连接到功能损伤。

**仍可被否定的必要预测。** 如果将来完整视频确认某配方有具体、稳定的功能缺陷，那么这个机制要求：在与缺陷有关的自然有限输入变化上，固定 code/scale 的微块仍承载有用 BF16 响应；LR 没有恢复这些方向，而实际跨胞元响应也没有补足。相近端点误差的普通扰动应不能同样解释该缺陷。仅证明 infinitesimal rank、低换码率、局部增量误差，或人工构造 LR nullspace 扰动都不满足这个预测。

**有功能观察以后才考虑的最小判别。** 冻结一处与该功能有可识别关系的模块和一个自然有限输入对，先精确区分 global 连续项、离散码/微尺度改变项、LR 项与 BF16 舍入；再比较只恢复目标有限响应与等能量无关方向恢复对同一完整功能的影响。只需要一次有限 oracle 诊断，不改 rank、scale 网格或 kernel。若恢复一般误差与恢复目标响应同样有效，就没有独特的“低秩连续通道”解释。当前没有合格功能读出，不启动这项诊断。

**停止条件。** 若自然有限变化已广泛跨胞元并保留所需响应；或 LR 已覆盖这些变化；或现象完全由 BF16 台阶/普通 activation 误差解释，停止此候选。若 whole-video 功能差异没有建立，则暂存代数边界，优先检查已有 E068 媒体；这属于缺证，不是机制阴性。当前建议新增实验数为 **0**。
