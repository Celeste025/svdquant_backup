# E212：同 map 旁路测量可省掉的净开销

保持真实 QKV、原版 pooled Q/K、score、最终路由、物化方式和主 kernel 相同，分阶段旁路池化、评分和排序。四组输出 NMSE 均为 0。每阶段预热，正反阶段顺序各 12 次 CUDA event 测量，共 24 次。首步捕获成本不包含在这里。

| 预算 | 粒度 | 原版完整调用 ms | 省去池化/评分/排序后 ms | 净省 ms | 净省比例 |
|---|---|---:|---:|---:|---:|
| 90% NVFP4 + 10% INT8 | Q128×K128 | 29.83 | 28.47 | 1.36 | 4.6% |
| 90% NVFP4 + 10% INT8 | Q64×K64 | 27.08 | 26.34 | 0.74 | 2.7% |
| 10% NVFP4 + 10% INT8 + skip80% | Q128×K128 | 14.54 | 13.23 | 1.32 | 9.1% |
| 10% NVFP4 + 10% INT8 + skip80% | Q64×K64 | 13.26 | 12.47 | 0.79 | 6.0% |

此前 E211 按各 kernel 时间及 prepare 差值估计的比例约为 5.5/3.9/11.4/7.9%，不等于完整调用能省下的墙钟时间。此处同 map 控制下的完整调用差值更适合回答后续缓存复用能省多少。执行流重叠、CPU dispatch 和采样波动使细小阶段差值不能当作独立 kernel 的精确耗时；个别评分阶段差值为负，视为低于该实验的稳定分辨能力。

旁路后仍量化并打包新的 QKV、计算 scales、执行前缀 attention、路由物化与主 attention。没有改变 map 来源或执行选块，不把不同 map 导致的主循环变化计入节省量。当前实际缓存路线还涉及缓存格式的细小开销，因此不是完整视频加速保证。只测同一组 480p/124 帧真实输入，未重跑视频。
