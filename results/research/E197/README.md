# E197：softmax 概率 Top-20 选块

沿用 E196 的四组赛车 BF16 轨迹捕获、Q128×K128 tile、真实 INT8/NVFP4 算子及两种预算。逐元素 FP32 softmax 对所有有效 key（含前缀）归一化；每个视频 tile 取概率最大的 20 个有效元素求和，不足 20 个则全部求和。

结果为视频区域相对于 BF16 dense attention 的 NMSE，均值为四组捕获的算术平均。step、layer 从 0 开始。

| 规则 | 10% INT8 + 15% NVFP4，跳过 75% | 10% INT8 + 90% NVFP4 |
|---|---:|---:|
| 原版 DraftMap | 0.0483110 | 0.0353164 |
| 概率均值 | 0.0279282 | 0.0262473 |
| 逐行最大概率之和 | 0.0283493 | 0.0261829 |
| 概率 Top-20 之和 | 0.0276470 | 0.0262678 |

## 校验与限制

- 用小于和大于 20 个有效元素的规则与不规则 tile 对照直接计算，校验 top-20、padding 及含前缀的 softmax。实际路由均解码后与稳定排序结果核对。
- 四组捕获校验 SHA-256，重新运行的 DraftMap 与 E196 对照在视频和前缀 NMSE 上完全一致。每个 head 的误差见本目录各 JSON。
- 这些算子结果来自同一 prompt 的四组捕获，不代表完整视频的 PSNR、LPIPS 或推理速度。
