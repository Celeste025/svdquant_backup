# E213：理论可移除工作量与实际净节省

理论口径：独立执行时的池化增量 + DraftMap 评分 + 排序路由耗时之和；不扣除完整路径中的并行重叠。池化融合在 preparation 内，用同输入有/无池化两种准备 kernel 的差值估计，故不是严格硬件上界。实际净节省沿用 E212 同 map 控制实验。两种比例均除以 E212 原版完整调用时间。

| 预算 | 粒度 | 理论可省 ms | 理论比例 | 实际净省 ms | 实际比例 |
|---|---|---:|---:|---:|---:|
| 90% NVFP4 + 10% INT8 | Q128×K128 | 1.51 | 5.1% | 1.36 | 4.6% |
| 90% NVFP4 + 10% INT8 | Q64×K64 | 0.97 | 3.6% | 0.74 | 2.7% |
| 10% NVFP4 + 10% INT8 + skip80% | Q128×K128 | 1.51 | 10.4% | 1.32 | 9.1% |
| 10% NVFP4 + 10% INT8 + skip80% | Q64×K64 | 0.96 | 7.3% | 0.79 | 6.0% |

分母是后续每次 attention full API 调用，不是整段视频 DiT 总时间；不包含首步捕获成本。仍需 QKV 量化、打包、scale、前缀、物化及混合 attention。不同测量口径下小于约 0.1ms 的差值需谨慎解读。原视频和算子代码未改。
