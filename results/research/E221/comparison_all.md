# 四视频实验对照：历史四组与新增五组

四视频等权平均；LPIPS 为逐帧 LPIPS-Alex 均值，PSNR 为逐视频全帧 RGB 全局 MSE 计算后对四视频均值。耗时为 p025 小猫麻将单次 20-step 同步 DiT 平均，不包括加载和解码。

| 方案 | 平均 LPIPS ↓ | 平均 PSNR ↑ | p025 秒/step ↓ |
|---|---:|---:|---:|
| 原版首步 QK map 捕获后复用 | 0.3020 | 17.78 dB | 15.46 |
| 原版每 5 步刷新 QK map | 0.2923 | 17.87 dB | 15.57 |
| Baseline：每步重建 DraftMap | 0.3028 | 17.87 dB | 15.31 |
| 首步 softmax 概率图捕获后复用 | 0.2679 | 18.37 dB | 16.13 |
| Baseline + 前 2 步保护（Q128） | 0.2302 | 19.49 dB | 15.54 |
| Baseline + 前 2 步保护 + Q64 | 0.2297 | 19.01 dB | 16.71 |
| 2–10 概率图捕获复用 + Q64 + 末 block | 0.2421 | 18.71 dB | 16.03 |
| 稀疏 baseline + 前 2 步保护（Q128） | 0.3498 | 16.55 dB | 12.84 |
| 稀疏 2–10 概率图复用 + Q64 + 末 block | 0.3303 | 16.76 dB | 13.39 |

E202 旧方案画质来自 E160/E161/E162，耗时来自 p025 单次复测；E202 概率首步方案使用两遍 INT8 QK 原型。新增复用方案使用 Q64 融合概率均值捕获，第 2 和第 10 步为 dense INT8；其第 0 主层保持 BF16，末层从第 3 步起为 20% INT8、80% 跳块。稀疏方案为 10% INT8、15% NVFP4、75% 跳块。不同运行的单次计时不构成严格速度基准。

数据来源：E202/first_comparison.json、E219/summary.json、E221/summary.json。
